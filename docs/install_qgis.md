# Встановлення QGIS

QGIS (раніше Quantum GIS) — це вільна настільна географічна інформаційна система (ГІС) з відкритим кодом, яка дозволяє переглядати, редагувати та аналізувати геопросторові дані. Це основна програма, яка потрібна для роботи плагіна **XML-UA**.

## Де завантажити?

Найбезпечніший спосіб отримати QGIS — завантажити його з **офіційного сайту**:

<a href="https://qgis.org/uk/site/forusers/download.html" target="_blank">**https://qgis.org/uk/site/forusers/download.html**</a>

## Яку версію обрати?

На сторінці завантаження ви побачите кілька варіантів. Для стабільної роботи, особливо в робочому середовищі, ми наполегливо рекомендуємо обирати **найновішу довготривалу версію (LTR — Long Term Release)**.

*   **Довготривала версія (LTR):** Найбільш стабільна. Вона отримує виправлення помилок протягом року, але не нові функції. Це ідеальний вибір для роботи.
*   **Остання версія:** Містить найновіші функції, але може бути менш стабільною. Підходить для ентузіастів, які хочуть випробувати нові можливості.



## Процес встановлення (для Windows)

1.  Перейдіть на <a href="https://qgis.org/uk/site/forusers/download.html" target="_blank">сторінку завантаження</a>.
2.  Знайдіть розділ **"Довготривала версія (найбільш стабільна)"** та натисніть на посилання для завантаження інсталятора для вашої операційної системи (наприклад, `QGIS-OSGeo4W-*-setup-x86_64.exe`).
3.  Запустіть завантажений файл `.exe`.
4.  Дотримуйтесь інструкцій інсталятора. Зазвичай достатньо натискати "Далі", погоджуючись з умовами ліцензії та залишаючи стандартні налаштування.
5.  Після завершення встановлення ви знайдете ярлик `QGIS Desktop` на вашому робочому столі або в меню "Пуск".

> Для інших операційних систем (macOS, Linux) інструкції також доступні на офіційній сторінці завантаження.

Тепер ви готові до встановлення плагіна XML-UA!
