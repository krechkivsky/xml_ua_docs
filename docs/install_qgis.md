# Встановлення QGIS 4.2

![QGIS logo](./images/QGIS_logo.jfif)

## Якщо ви робите XML в інших програмах

Перехід на QGIS не означає, що потрібно забути інші програми або заново вчитися землевпорядкуванню. Ваше розуміння координат, меж, здвоєних точок і напрямку обходу контурів нікуди не зникає — це найважливіша частина роботи, і вона вже у вас є.

QGIS — інша програма, але **xml_ua допомагає перенести у неї звичну роботу з кадастровим XML**. Плагін автоматично коригує порядок додавання геометричних об’єктів і напрямок обходу контурів, а під час роботи показує помилки та підказки. Не треба самотужки вгадувати, що саме не сподобалося файлу.

А ще QGIS безплатний. Його можна встановити й освоювати, не купуючи ліцензію та не відмовляючись від інших програм. Знання QGIS — корисна додаткова навичка: вона може розширити вибір проєктів і вакансій, де потрібна робота з картами та геоданими.

QGIS підходить для різних масштабів роботи: окремий фахівець може налаштувати власну ГІС і готувати потрібну документацію, громада — збирати й аналізувати свої кадастрові дані, а на національному рівні QGIS може бути одним з інструментів для роботи із земельними даними. 

## Завантажте QGIS 4.2

Завантажуйте програму лише з <a href="https://qgis.org/download/" target="_blank">офіційного сайту QGIS</a> — програма безплатна.

Для звичайного комп’ютера з Windows:

1. Відкрийте <a href="https://qgis.org/download/" target="_blank">сторінку завантаження QGIS</a> і виберіть Windows.
2. Серед запропонованих файлів виберіть **інсталятор QGIS 4.2 для Windows 64-bit**.
3. Відкрийте завантажений файл. У майстрі встановлення погодьтеся зі стандартними параметрами — для першого знайомства цього достатньо.
4. Після завершення запустіть **QGIS 4.2** через меню «Пуск».
5. Щоб перевірити версію, відкрийте **Довідка → Про програму**.

Встановлення QGIS **не видаляє інші програми**. Всі програми можуть бути на комп’ютері одночасно; ви самі вирішите, коли і для яких задач користуватися кожною.

## Чого чекати від першого запуску?

QGIS — це повноцінна ГІС, а не лише програма для створення XML. Спершу вікно може здатися незнайомим: у ньому є карта, шари та панелі інструментів. Не потрібно вивчати все одразу. Для початку достатньо запустити QGIS, встановити плагін **xml_ua** і відкрити знайомий кадастровий XML.

Працюйте з геометрією як і раніше: автоматизація допомагає з порядком об’єктів та обходом контурів, але не замінює вашу професійну перевірку. А коли щось не так, xml_ua підсвітить помилку й покаже підказку просто під час роботи.

Якщо ви вже працювали в інших програмах, ви починаєте не з нуля — ви додаєте до свого досвіду ще один сучасний інструмент.
