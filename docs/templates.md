# Шаблони

Шаблони — це потужний інструмент плагіна **xml_ua**, призначений для значного прискорення роботи та зменшення кількості рутинних операцій.

## Що таке шаблон?

Простими словами, шаблон — це звичайний обмінний файл `.xml`, який ви підготували заздалегідь. Він може бути частково або повністю заповнений атрибутивною інформацією (даними про виконавця, замовника, систему координат тощо), але з нього **видалені просторові дані**, тобто геометрія конкретної земельної ділянки.

Це, по суті, ваша персональна "заготовка" для майбутніх проєктів.

## Навіщо потрібні шаблони?

Уявіть, що ви створюєте декілька обмінних файлів для земельних ділянок, які:
*   знаходяться в межах однієї сільської ради;
*   розробляються одним і тим же сертифікованим інженером-землевпорядником;
*   передаються в оренду одному й тому ж орендарю.

У цьому випадку більшість службової інформації буде абсолютно однаковою для всіх файлів. Щоб не вводити ці дані щоразу заново, ви можете один раз заповнити файл, зберегти його як шаблон, а потім використовувати його для всіх наступних ділянок.

## Практичний приклад

1.  Відкрийте або створіть один обмінний файл та ретельно заповніть у ньому всю повторювану інформацію: дані про виконавця, замовника, органи влади, орендаря, систему координат тощо.
2.  Використайте функцію меню **Зберегти як шаблон...**.
3.  Дайте шаблону зрозумілу назву, наприклад, `Іванівська_сільрада_ТОВ_Агро`.

Тепер, коли вам потрібно створити новий обмінний файл для цієї місцевості:

1.  Намалюйте полігон нової ділянки на карті та виділіть його.
2.  Натисніть правою кнопкою миші на карті та в контекстному меню виберіть **Створити XML з шаблону -> Створити з 'Іванівська_сільрада_ТОВ_Агро'**.

Плагін миттєво створить новий XML-файл, де всі дані з вашого шаблону вже будуть заповнені. Вам залишиться лише додати унікальну інформацію (наприклад, дані про власника ділянки) та уточнити її геометрію.

Використання шаблонів значно прискорює роботу, зменшує ризик механічних помилок і робить процес створення обмінних файлів більш ефективним.

> **Примітка:** Не хвилюйтеся, що ви можете створити занадто багато шаблонів. Ви завжди можете видалити непотрібні або заархівувати їх, просто керуючи файлами у підпапці `templates` всередині [папки плагіна](plugin_folder.md).
>
