
# Системи координат (СК)

QGIS дозволяє одночасно працювати з даними у різних системах координат, автоматично "на льоту" перетворюючи їх для спільного відображення. Однак для точних кадастрових робіт такий підхід може бути небезпечним і призвести до помилок.

Уявіть, що система координат — це "мова", якою ми описуємо, де саме на Землі знаходиться земельна ділянка. Якщо дві карти використовують різні "мови" (системи координат), то одна й та сама ділянка на них матиме різні координати і може навіть виглядати трохи інакше.

## Чому це важливо?

*   **Точність:** При роботі з різними системами координат ділянка може "з'їхати" на кілька сантиметрів або навіть метрів. Це може призвести до накладок на сусідні ділянки та серйозних юридичних проблем.
*   **Перетворення (репроєкція):** Перетворення координат з однієї системи в іншу не завжди є ідеальним. Це схоже на переклад вірша з однієї мови на іншу — частина точності може бути втрачена.

> **Головне правило:** Завжди намагайтеся працювати в тій системі координат, яка історично використовувалася для вашої території. Це найкращий спосіб уникнути помилок.

## "Проблема" СК-63

Особливу увагу варто приділити **системі координат 1963 року (СК-63)**. Величезна кількість земельних ділянок в Україні була обміряна саме в цій системі. Основна проблема полягає в тому, що СК-63 була "умовною" — кожна область (а іноді й район) мала свої власні зони та параметри перерахунку.

Це означає, що не існує єдиного універсального способу перетворити координати з СК-63 в сучасну УСК-2000. Перерахунок завжди потребує локальних ключів (параметрів трансформації), і без них точність може бути втрачена, що призводить до зміщень та накладок ділянок. Саме тому так важливо знати, в якій системі координат велася зйомка, і використовувати відповідні параметри.

### Як задати користувацьку СК-63 для відомої зони

Якщо вам відома **зона СК-63**, ви можете створити її як **користувацьку СК** в QGIS і призначати шарам/проєкту без пошуку коду EPSG:

1. Відкрийте **Налаштування (Settings) → Користувацькі системи координат… (Custom Projections…)**.
2. Натисніть **Додати нову (Add new)**, задайте назву (наприклад, `СК-63 зона X`).
3. У полі параметрів вставте PROJ-рядок потрібної зони (див. нижче) і збережіть.
4. Призначте створену СК для шару (**Властивості шару → Джерело → Призначити СК**) або для проєкту (**Властивості проєкту → СК**).

**СК-63 зона X**
```proj
+proj=tmerc
+lat_0=0
+lon_0=24
+k=1
+x_0=1500000
+y_0=0
+ellps=krass
+units=m
+no_defs
```

**СК-63 зона C**
```proj
+proj=tmerc
+lat_0=0
+lon_0=30
+k=1
+x_0=2500000
+y_0=0
+ellps=krass
+units=m
+no_defs
```

**СК-63 зона P**
```proj
+proj=tmerc
+lat_0=0
+lon_0=36
+k=1
+x_0=3500000
+y_0=0
+ellps=krass
+units=m
+no_defs
```

**СК-63 зона T**
```proj
+proj=tmerc
+lat_0=0
+lon_0=42
+k=1
+x_0=4500000
+y_0=0
+ellps=krass
+units=m
+no_defs
```

> Якщо потрібно не лише *задати СК*, а й *перерахувати* координати з/в інші СК з високою точністю, можуть знадобитися локальні параметри трансформації (ключі), які залежать від вашої території та вихідних матеріалів.

## Дозволені системи координат

<a href="https://zakon.rada.gov.ua/laws/show/1051-2012-%D0%BF#Text" target="_blank">Порядок ведення Державного земельного кадастру</a> визначає перелік систем координат, які можна використовувати в обмінних файлах XML:

*   **УСК-2000 (USC2000):** Сучасна державна геодезична референцна система координат України. Є пріоритетною для нових робіт.
*   **СК-42 (SC42 та SC42_3):** Державна система координат 1942 року (в 6-градусних та 3-градусних зонах). Дуже поширена, в ній виконано величезний обсяг робіт у минулому.
*   **СК-63 (SC63):** Умовна система координат 1963 року. Також часто зустрічається в архівних матеріалах.
*   **Місцева система координат (Local):** Система, утворена від однієї з державних систем для потреб конкретного міста чи території.
*   **WGS-84:** Світова геодезична система, яку використовує GPS. Зазвичай не використовується для кадастрових робіт в Україні, але може знадобитися для інтеграції з глобальними сервісами.

## Коди EPSG

У програмах, як-от QGIS, кожна система координат має унікальний ідентифікатор — **код EPSG**. Наприклад, для УСК-2000 це може бути код `EPSG:6381`, а для однієї із зон СК-42 — `EPSG:28407`.

Знайти потрібний код для вашої території можна на спеціалізованих ресурсах, наприклад, на сайті <a href="https://epsg.io/?q=Ukraine" target="_blank">epsg.io</a>.
