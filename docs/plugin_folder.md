# Папка плагіна

Папка плагіна — це місце на вашому комп'ютері, де QGIS зберігає всі встановлені розширення, включаючи **xml_ua**. Знання цього шляху може бути корисним для ручного встановлення, оновлення або видалення плагінів, а також для доступу до файлів шаблонів.

## Як знайти папку плагіна?

Найпростіший спосіб знайти папку з профілем користувача, де зберігаються плагіни, — безпосередньо з QGIS:

1.  Відкрийте QGIS.
2.  Перейдіть до меню **Налаштування -> Профілі користувача -> Відкрити теку активного профілю**.

Це відкриє папку вашого поточного профілю. Плагіни знаходяться всередині підпапки `python\plugins`.

### Типові шляхи для Windows

Шлях до папки плагінів може відрізнятися залежно від версії Windows та способу встановлення QGIS.

#### Стандартне встановлення QGIS

Зазвичай, для профілю за замовчуванням (`default`), шлях виглядає так:

`C:\Users\[Ваше ім'я користувача]\AppData\Roaming\QGIS\QGIS3\profiles\default\python\plugins`

> **Примітка:** Папка `AppData` за замовчуванням є прихованою. Щоб її побачити, вам потрібно увімкнути відображення прихованих файлів та папок у налаштуваннях "Провідника" Windows.
